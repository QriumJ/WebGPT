# Tag normalizer

Implement `normalizeTags(values)` in `normalize-tags.mjs` as a named export. Input is an array of strings. Trim surrounding whitespace, lowercase, discard empty tags, remove duplicates, and preserve first occurrence order. Never mutate the input. Throw TypeError for a non-array or any non-string element. Add concise Node built-in tests in `normalize-tags.test.mjs`; use no dependencies.
